*OKOHO Académie · Parcours Claude Pro · Séances M05-S1 et M03-S1*

::: objectifs
- Vous ajoutez quatre sources à votre notebook « Parcours Claude Pro ».
- Vous générez un résumé audio, un quiz et des cartes de révision en français.
- Vous vous entraînez à construire une page web à partir d'un blocage, à la publier proprement et à vérifier chaque information.

## Les huit consignes

Dans le panneau **Studio**, choisissez le format, puis collez la consigne dans le champ de personnalisation. Réglez la langue de sortie sur **Français**.

**1. Résumé audio**

::: prompt
Public : des entrepreneurs, des responsables d'école ou de centre de santé et de futurs prestataires digitaux au Cameroun, débutants avec l'intelligence artificielle. Sujet : les séances M05-S1 « Une page web en une conversation » et M03-S1 « Vérifier : erreurs, sources, limites » du Parcours Claude Pro (OKOHO Académie). Objectif : que l'auditeur sache créer une page web à partir du blocage d'un client, l'améliorer par des tours ciblés, la publier et la contrôler, puis vérifier chaque information avec une source. Concentrez-vous sur : le gabarit de la page, les quatre parties d'une page v1, la publication dans le navigateur, la navigation privée, les trois questions avant d'utiliser une information, la règle « les prix viennent du client ». Exemples variés : un atelier, une école, un centre de santé, une association. Terminez par les trois actions à faire après l'écoute. Langue : français, ton clair et encourageant.
:::

**2. Aperçu vidéo**

::: prompt
Créez une vidéo explicative pour des débutants au Cameroun sur les séances M05-S1 et M03-S1. Montrez dans l'ordre : le blocage d'un client, la fiche contexte, le gabarit de la page, la page créée par Claude, deux tours ciblés, la publication dans le navigateur, le contrôle du lien en navigation privée, la liste des informations à vérifier, la recherche d'une source officielle, le message au client pour confirmer ses prix. Pour chaque étape : ce qu'on fait, pourquoi, l'erreur à éviter. Langue : français. Phrases courtes. Un message clé par écran.
:::

**3. Carte mentale** (aucune consigne à coller). Après la création, demandez dans le chat :

::: prompt
À partir de la carte mentale, expliquez-moi en 5 phrases pourquoi une page web n'est prête à publier qu'après la vérification de chaque information.
:::

**4. Guide d'étude**

::: prompt
Rédigez un guide d'étude en français pour les séances M05-S1 et M03-S1. Structure : 1. Objectifs · 2. Notions clés avec définition simple (artefact, publier, lien public, navigation privée, hallucination, source officielle) · 3. Les étapes pratiques · 4. Erreurs fréquentes · 5. Cinq questions de réflexion · 6. Application dans trois métiers différents au Cameroun. Longueur : 2 pages maximum.
:::

**5. Cartes de révision**

::: prompt
Créez des cartes de révision sur les séances M05-S1 et M03-S1. Concentrez-vous sur : les quatre parties d'une page v1, le tour ciblé, où publier, comment contrôler un lien, ce qu'il faut vérifier, la différence entre une source officielle et un message transféré, d'où viennent les prix. Recto : une situation courte dans un métier. Verso : ce qu'il faut faire, en une phrase.
:::

**6. Quiz**

::: prompt
Créez un quiz en français sur les séances M05-S1 et M03-S1. Chaque question se passe dans un métier différent : commerce, école, centre de santé, restaurant, atelier, association, pharmacie, transport. Vérifiez : choisir l'objectif d'une page, reconnaître les quatre parties, écrire un tour ciblé, savoir où publier, contrôler un lien, repérer une information inventée, choisir une source officielle, demander les prix au client. Expliquez chaque bonne réponse.
:::

**7. Diaporama**

::: prompt
Créez un diaporama en français de 6 à 8 diapositives sur les séances M05-S1 et M03-S1. Une idée clé par diapositive. Public : le gérant d'un petit commerce qui reçoit tous les jours les mêmes questions de ses clients. Dernière diapositive : les trois gestes pour avoir une page juste, en ligne, dès demain.
:::

**8. Infographie**

::: prompt
Créez une infographie en français qui résume les séances M05-S1 et M03-S1 sur une seule page. Contenu : du blocage au lien en quatre étapes, les quatre parties d'une page v1, les trois contrôles avant de publier, les trois questions avant d'utiliser une information. Peu de texte, facile à lire sur un téléphone.
:::
