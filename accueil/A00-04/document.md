::: objectifs
- Vous savez ce qu'est votre portfolio et à quoi il vous sert, pendant le parcours et après.
- Vous ouvrez votre portfolio sur votre téléphone ou votre tablette.
- Vous y déposez une preuve, avec le bon nom de fichier, et vous vérifiez qu'elle est arrivée.
:::

## Pourquoi c'est utile

Votre portfolio est votre classeur de preuves. Chaque semaine, vous y rangez ce que vous avez produit : captures, textes, pages, documents. Le formateur y lit vos livrables et les évalue. Au Démo Day, vous l'ouvrez devant le groupe pour montrer ce que vous savez faire.

Plus tard, ce même portfolio devient votre vitrine de prestataire : vous montrez à un futur client des travaux réels, réalisés pour un vrai client pilote.

Votre portfolio est un dossier Google Drive. Vous seul et le formateur le voyez. Les autres participants ne le voient pas.

Durée : 15 minutes la première fois, puis une minute par dépôt. Appareil : téléphone, tablette ou ordinateur.

## Avant de commencer

- [ ] Vous avez donné votre adresse Gmail dans le formulaire **S00-2 · Diagnostic d'entrée**.
- [ ] Vous avez reçu un e-mail de Google : « … a partagé un dossier avec vous : Portfolio · [votre prénom] ».
- [ ] L'application **Google Drive** est installée et connectée avec cette même adresse Gmail.

Pas d'e-mail ? Regardez dans le dossier « Spam » ou « Promotions ». Toujours rien : écrivez votre adresse Gmail au formateur en message privé sur WhatsApp.

## Ce qu'il y a dans votre portfolio

| Ce que vous déposez | Quand | Exemple de nom |
|---|---|---|
| Les preuves et le livrable de chaque séance | Chaque semaine, avant la date indiquée | S03-1_Aicha.png |
| Votre **Dossier client pilote** (déjà dans votre portfolio) | Vous le complétez au fil des séances | Dossier client pilote · Aicha.docx |

**La règle du nom :** code de la séance, tiret bas, votre prénom, puis l'extension. Par exemple **S03-1_Aicha.png**. Plusieurs fichiers pour la même séance : ajoutez un numéro, **S03-1_Aicha_2.png**. Pas de « : » dans le nom.

## Étape 1 : ouvrir votre portfolio une première fois

1. Ouvrez l'e-mail de Google et touchez **Ouvrir**.
2. Le dossier s'ouvre dans l'application Google Drive.
3. Pour le retrouver vite, touchez les trois points **⋮** du dossier, puis **Ajouter un raccourci dans Drive** ou l'**étoile**.
4. Les fois suivantes : ouvrez Google Drive, onglet **Partagés**, puis **Portfolio · [votre prénom]**.

Les libellés peuvent varier un peu selon votre téléphone et la version de l'application.


## Étape 2 : déposer une preuve

1. Faites votre capture d'écran comme d'habitude.
2. Ouvrez votre portfolio dans Google Drive.
3. Touchez le bouton **+** en bas à droite.
4. Touchez **Importer**, puis choisissez votre capture dans vos photos.
5. Attendez la fin de l'envoi : le fichier apparaît dans le dossier.


## Étape 3 : renommer le fichier

1. Touchez les trois points **⋮** à côté du fichier.
2. Touchez **Renommer**.
3. Écrivez le nom selon la règle, par exemple **S03-1_Aicha.png**, puis **OK**.


## Étape 4 : vérifier

- [ ] Le fichier est dans **votre** portfolio, pas dans « Mon Drive ».
- [ ] Le nom suit la règle : code, tiret bas, prénom.
- [ ] Le fichier s'ouvre quand vous le touchez.

C'est tout : le formateur voit le fichier, vous n'avez rien à lui envoyer.

## Votre Dossier client pilote

Le fichier **Dossier client pilote** est déjà dans votre portfolio. Ouvrez-le avec Google Docs ou Word et complétez la page de chaque séance. Le dossier grandit avec vous : au Démo Day, il montre le blocage de votre client pilote, au moins trois produits réalisés et l'effet observé.

::: coup-de-pouce
1. Le bouton **+** n'apparaît pas ? Vous n'êtes pas dans votre portfolio : ouvrez l'onglet **Partagés**, puis le dossier.
2. Google Drive vous demande de vous connecter ? Utilisez exactement l'adresse Gmail donnée dans le diagnostic, sinon le dossier reste invisible.
3. Rien ne fonctionne ? Envoyez votre capture au formateur en message privé sur WhatsApp, avec le nom de fichier prévu. C'est une solution de dépannage, une seule fois.
:::

::: erreurs
- **Envoyer ses preuves dans le groupe WhatsApp.** Le groupe sert aux questions. Les preuves vont dans le portfolio.
- **Garder le nom « Screenshot_2047.png ».** Sans le bon nom, le formateur ne trouve pas votre preuve.
- **Déposer des données sensibles.** Pas de pièce d'identité, de donnée bancaire, de note ou de nom d'élève, de dossier de patient.
:::
